安装与使用指南

简单几步，即可在各大主流浏览器中使用

  1. 从 GitHub Releases 页面下载最新版 wxt 或解压扩展包至本地目录。
  2. 打开浏览器扩展管理页面：Chrome 请在地址栏输入 chrome://extensions，Edge 请输入 edge://extensions。
  3. 在右上角开启 “开发者模式” (Developer mode) 开关。
  4. 点击左上角的 “加载已解压的扩展程序” (Load unpacked) 按钮。
  5. 在弹出的文件选择框中选择解压出来的插件根目录，完成安装。
  1. 打开 Firefox 浏览器，在地址栏输入 about:debugging#/runtime/this-firefox 并按回车。
  2. 点击右上方的 “临时加载附加组件...” (Load Temporary Add-on...) 按钮。
  3. 在文件选择对话框中，选择解压包中的 manifest.json 文件。
  4. 扩展加载成功后即可在扩展栏菜单中开始使用。
  • 搜索延迟设置：推荐开启“随机延迟”，建议间隔设置为 3 ~ 8 秒，模拟真实人类搜索行为。
  • 账号状态：请确保您已在 rewards.bing.com 登录 Microsoft 账号。
  • 后台定时任务：开启自动触发搜索功能后，保持浏览器后台运行即可自动按设定完成每日任务。
